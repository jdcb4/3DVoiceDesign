VoiceDesign3D API

Local CAD API v1. Lengths are millimeters; volumes are cubic millimeters. This reference works offline.

Viewer · OpenAPI JSON · Capabilities · Batch schema

Read a design's /features, then send its revision as expected_revision with your operation batch. Success means verified and saved. HTTP 409 requires rereading and reconciling; 422 means the requested batch was not saved. After a timeout or lost response, inspect the trace and current revision before retrying. Trace IDs detect duplicates; they do not replay cached responses.

Allow 120 seconds for a batch (CAD execution has a 90-second limit; queue time is additional). Ordinary requests use a 15-second client timeout. No automatic write retries.
